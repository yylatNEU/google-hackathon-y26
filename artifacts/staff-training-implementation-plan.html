Operating Model

01

Scenario

Employee chooses a guest-interaction scenario such as lost child, refund request, accessibility support, or safety-rule refusal.

02

Guest Turn

Vertex AI generates the next guest reply only. It cannot score, approve refunds, dispatch work, or reveal rubric details.

03

Employee Reply

The trainee responds in natural language, practicing empathy, clarity, safety, policy handling, and escalation judgment.

04

Scoring

The deterministic backend rubric scores the response and caps critical misses where safety or escalation is absent.

05

Coaching

The app shows what worked, what to fix, weak dimensions, and a recommended next response for practice.

Backend Contracts

  • Vertex transport must be vertex_ai_rest when Vertex mode is configured.
  • LLM guest generation must return or fall back inside the hard timeout budget.
  • Official score is deterministic and never controlled by Vertex output.
  • Golden eval endpoint must pass all calibration cases before scoring changes ship.
  • Training data stays simulated and never feeds live operations or reward labels.

Build Plan

Phase Status Scope Exit Criteria
1. Core Roleplay Done Scenario catalog, session start, employee turn, guest follow-up, deterministic scoring. Start roleplay works, response box unlocks, scoring returns without hangs.
2. Vertex Integration Done Vertex AI REST guest generation, provider status, hard timeout fallback. Live payload reports vertex_ai_rest and llm_controls_score false.
3. Scoring Calibration Done Golden response fixtures for bad, partial, passing, excellent bands. /api/park/staff-training/golden-eval returns pass with zero failures.
4. Manager Review Next Expose golden eval summary and recent trainee readiness in the manager tab. Manager can see scoring health, readiness holds, and retry recommendations.
5. Multi-Turn Mastery Next Track whether a trainee repairs missed safety, escalation, or clarity signals across turns. Debrief distinguishes one good reply from sustained scenario control.
6. Shadow Evaluator Next Add optional LLM-as-judge commentary for rubric disagreements without score authority. Shadow evaluator can explain drift, but deterministic score remains official.

Risks To Watch

  • Keyword scoring can still miss nuanced but policy-correct language.
  • Golden fixtures need real trainer review before production use.
  • Vertex latency must stay bounded with visible fallback status.
  • Manager sign-off should not be automated solely from simulated scores.
